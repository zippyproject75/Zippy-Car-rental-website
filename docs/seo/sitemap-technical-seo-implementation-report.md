### Language Alternates

**Format:** BCP 47 language tags with x-default

**Example (Homepage):**
```xml
<url>
  <loc>https://www.zippycarrental.in</loc>
  <xhtml:link rel="alternate" hreflang="en-IN" href="https://www.zippycarrental.in" />
  <xhtml:link rel="alternate" hreflang="hi-IN" href="https://www.zippycarrental.in/hi" />
  <xhtml:link rel="alternate" hreflang="mr-IN" href="https://www.zippycarrental.in/mr" />
  <xhtml:link rel="alternate" hreflang="x-default" href="https://www.zippycarrental.in" />
</url>
```

**Example (Vehicle Page):**
```xml
<url>
  <loc>https://www.zippycarrental.in/cars/fronx</loc>
  <xhtml:link rel="alternate" hreflang="en-IN" href="https://www.zippycarrental.in/cars/fronx" />
  <xhtml:link rel="alternate" hreflang="hi-IN" href="https://www.zippycarrental.in/hi/cars/fronx" />
  <xhtml:link rel="alternate" hreflang="mr-IN" href="https://www.zippycarrental.in/mr/cars/fronx" />
  <xhtml:link rel="alternate" hreflang="x-default" href="https://www.zippycarrental.in/cars/fronx" />
</url>
```

## Robots.txt Implementation Details

### Current Robots.txt Configuration

**Implementation:** Native Next.js App Router robots (`production/src/app/robots.ts`)

**Content:**
```
User-agent: *
Allow: /

Sitemap: https://www.zippycarrental.in/sitemap.xml
```

**Rationale:**
- Allow crawling of all pages so crawlers can observe individual page robots meta tags
- Individual page indexing controlled by meta tags and X-Robots-Tag headers
- Sitemap directive points to production sitemap
